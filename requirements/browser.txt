# What runs in the browser. Mirrors what ovos-installer puts on a device
# (ansible/roles/ovos_virtualenv/templates/virtualenv/*-requirements.txt.j2),
# minus the parts that are hardware: listener, audio service, PHAL.
# Built with `pip wheel --pre`, i.e. the alpha channel.

# core-requirements.txt.j2: ovos-core[plugins], public speech (the installer's
# default). Emkay names the plugins of that group one by one, as it does the
# skills below, and leaves out what a browser can't use or Emkay doesn't:
# padacioso (a second padatious, not in the pipeline), the translation
# plugins (ovos-bidirectional-translation-plugin, ovos-translate-server-plugin:
# OVOS' translation servers, which a web page may not ask and which would send
# what you say out of the house; offline translation needs native code) and
# ovos-persona (no persona is set up, and it brings ovos-openai-plugin along).
# Any of them can be installed from the control panel. Check against
# ovos-core's "plugins" extra when it changes.
ovos-core

ovos-padatious
